\# AES Cryptography Testing Project



\## 📌 Project Description



This project demonstrates testing of AES encryption and decryption using two different Python cryptographic libraries:



\- PyCryptodome

\- Cryptography



The goal is to compare implementations, verify correctness, and measure performance using automated tests.
